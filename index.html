Configurar nube

Para sincronizar tus datos entre dispositivos necesitas una base de datos Supabase gratuita.
Solo hay que hacerlo una vez.

1 Crea una cuenta gratis en supabase.com y crea un nuevo proyecto.
2 En el panel de Supabase ve a SQL Editor y ejecuta:

CREATE TABLE finanzas (id TEXT PRIMARY KEY, data JSONB);
3 Ve a Project Settings → API y copia la Project URL y la clave anon public.
